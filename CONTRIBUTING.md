# Contributing

Thanks for taking the time to help. Every repository under [@juw12](https://github.com/juw12) is
MIT licensed and welcomes issues, ideas and pull requests.

## Quick start

1. **Search first.** Check open issues so we don't duplicate work.
2. **Open an issue** for anything bigger than a typo, so we can agree on the approach before you write code.
3. **Fork and branch** from `main` (`fix/short-name` or `feat/short-name`).
4. **Keep it focused.** One change per pull request, with a clear description of what and why.
5. **Test it.** Run the project's existing tests or checks (see its README). Add a test when you fix a bug.
6. **Open the pull request** and fill in the template. Screenshots help for anything visual.

## Style

- Follow the conventions already used in the file you're editing.
- Write commit messages in the imperative mood: `Fix crash when list is empty`.
- Don't commit secrets, API keys, `.env` files, personal data or large binaries.

## Licensing of contributions

By submitting a contribution you agree that it is licensed under the
[MIT License](https://opensource.org/license/mit), the same license as the project
(inbound = outbound). You confirm you have the right to submit it. Signing off your commits
(`git commit -s`, the [Developer Certificate of Origin](https://developercertificate.org/))
is appreciated but not required.

## Code of Conduct

This project follows the [Contributor Covenant](CODE_OF_CONDUCT.md). By participating you agree to uphold it.

## Security issues

Please **don't** open a public issue for a vulnerability. See [SECURITY.md](SECURITY.md).
