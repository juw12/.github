# juw12/.github

Default community health files for every repository owned by [@juw12](https://github.com/juw12).
GitHub uses these automatically in any repository that doesn't have its own copy.

| File | Purpose |
| --- | --- |
| [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) | Contributor Covenant 2.1 |
| [CONTRIBUTING.md](CONTRIBUTING.md) | How to contribute; contributions are MIT licensed (inbound = outbound) |
| [SECURITY.md](SECURITY.md) | Private vulnerability reporting policy |
| [SUPPORT.md](SUPPORT.md) | Where to get help |
| [Issue forms](.github/ISSUE_TEMPLATE) | Bug report and question / idea forms |
| [PR template](.github/pull_request_template.md) | Pull request checklist |
