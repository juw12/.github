# Getting help

- **Read the README** of the project. Most projects have a landing page at
  [juw12.github.io/p/](https://juw12.github.io/p/) with screenshots and setup steps.
- **Questions or ideas:** open an issue using the *Question / idea* form.
- **Bugs:** open an issue using the *Bug report* form, with steps to reproduce.
- **Security problems:** follow [SECURITY.md](SECURITY.md). Please don't post them publicly.

These are personal projects maintained in spare time, so replies may take a few days.
